Includes UTAE, UNet3D, and ConvLSTM for crop type classification, phenology prediction, and yield estimation. |

Detects sarcasm, identifies targets, and fuses text and image inputs via a modified BART encoder with cross-attention and Vision Transformer features. Evaluated on MORE+ with BLEU, ROUGE, and METEOR. |
