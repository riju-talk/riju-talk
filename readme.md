## Projects

### Research Systems

| Project | Description |
|---------|-------------|
| [**Sickle++**](https://github.com/riju-talk/sickle-plus-plus) | Satellite crop monitoring with training, evaluation, and Earth Engine download utilities. Ingests multi sensor imagery (Sentinel 2, Sentinel 1, Landsat 8) in cell based and plot based formats. Includes UTAE, UNet3D, and ConvLSTM for crop type classification, phenology prediction, and yield estimation. |

### ML Systems

| Project | Description |
|---------|-------------|
| [**MineMEETS**](https://github.com/riju-talk/MineMEETS) | End to end ML pipeline system for data ingestion, feature workflows, experiment tracking, and production deployment patterns. |
| [**TURBO**](https://github.com/riju-talk/TURBO) | Independent implementation of Target Augmented Shared Fusion based Multimodal Sarcasm Explanation. Detects sarcasm, identifies targets, and fuses text and image inputs via modified BART encoder with cross attention and Vision Transformer features. Evaluates on MORE+ dataset with BLEU, ROUGE, and METEOR. |
